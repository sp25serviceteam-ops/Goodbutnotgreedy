The problem

Every manual order becomes admin twice.

Texts, calls and half-finished messages leave somebody to interpret the order, find the right account and rebuild it in Xero. The work is repetitive; the mistakes are not.

“Can we get the same as last week… plus cups… actually make that two decafs?”

Care Pack gives the cafe the current catalogue and a proper confirmation step, so the order arrives as an order. It is not a message that still needs interpreting.

How it works

From cafe link to Xero draft.

A short path for the cafe, with the controls a roaster actually needs behind it.

01 / LINK

Open

The cafe opens its own private ordering link in the browser. There is no app to install and no customer password to remember.

02 / ORDER

Choose

They see the products you have made visible to them, including customer-specific coffee codes, minimums and delivery information.

03 / CHECK

Confirm

The order is reviewed before it is sent. Empty orders are blocked and sold-out products do not make it onto an invoice.

04 / XERO

Draft

A draft invoice is created against the matched Xero contact. Coded items use Xero's item master for pricing, not a price sent by the browser.
